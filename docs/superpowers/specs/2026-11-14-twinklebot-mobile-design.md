# TwinkleBot 移动端（Mobile Client）技术架构与开发规范 (SPEC)

## 0. 给编程智能体（Coding Agent）的指令
本规范用于指导 **TwinkleBot** 移动端（iOS / Android）的架构改造、多端适配与构建打包。
**核心原则**：移动端与桌面端 **100% 共用同一套前端源码工程**，不拆分独立仓库。移动端在构建打包时物理剔除后端服务，作为**纯客户端（Pure Client）**运行，通过连接局域网电脑后端（本地账号）或公网服务器后端（云端账号）实现全部功能。

> **关于 UI 设计参考图的重要约定**：
> 提供的 5 张手机端设计截图仅作为**视觉风格、深色质感、间距排版与交互手势**的参考（原图包含部分外部产品占位文案如 `Grok Bot`、`管理订阅`、`1Password`、`Android`、`语音通话`）。实现时必须**全部对齐 TwinkleBot 的真实品牌名称与现有能力模块**（详见第 4.1 节映射规则），切勿照抄占位文案或实现空壳页面。

## 1. 核心架构：同源构建、原生壳与条件裁剪（无内置后端）

### 1.1 纯客户端定位 (Pure Client)
- **无内置后端**：手机端 App 仅包含纯前端交互界面（UI Client），**不包含**任何本地内置后端服务、本地数据库或本地容器沙箱，也不作为执行系统命令的宿主机。
- **职责边界**：手机端的所有业务逻辑、大模型对话、Bot 管理及电脑操控，完全依赖于其当前网络连接的远程后端（局域网内的电脑端本地后端，或公网上的云端服务器后端）。

### 1.2 构建期条件裁剪与原生容器选型
由于移动端需要调用底层网络能力（mDNS/UDP 局域网发现、获取本机子网 IP、系统生命周期与明文局域网通信配置），纯浏览器 WebView JS 无法直接完成，因此移动端采用 **Capacitor** 包裹同源前端构建产物，并通过编译期环境变量（`APP_TARGET=desktop | mobile`）区分打包行为：

- **桌面端打包 (`APP_TARGET=desktop`)**：
  1. 构建前端静态资源 + 打包桌面端 Electron 应用与内置后端。
  2. 将后端随桌面安装包发布，客户端启动时在后台拉起本地后端，应用退出时自动回收。
- **移动端打包 (`APP_TARGET=mobile`)**：
  1. **物理剔除后端**：构建脚本仅打包前端静态资源（HTML/CSS/JS）至 `dist-web/` 并同步至 Capacitor iOS / Android 工程，**完全剔除**后端源码与二进制文件，生成纯客户端安装包（APK / IPA）。
  2. **运行时跳过本地进程**：移动端启动时，根据 `APP_TARGET === 'mobile'`（及原生 Capacitor 运行时环境）跳过拉起本地后端进程与回环默认连接逻辑，直接进入原生插件网络初始化、本地凭证读取与远程连接流程。
  3. **原生系统权限与局域网明文放行配置（必须落实在打包配置中）**：
     - **iOS (`Info.plist`)**：配置 `NSLocalNetworkUsageDescription`、`NSBonjourServices`（`_twinklebot._tcp`），以及 `NSAppTransportSecurity` 下开启 `NSAllowsLocalNetworking = true`。
     - **Android (`AndroidManifest.xml` / `network_security_config.xml`)**：声明 `INTERNET`、`ACCESS_NETWORK_STATE`、`ACCESS_WIFI_STATE`、`CHANGE_WIFI_MULTICAST_STATE` 权限，并开启局域网明文流量支持。

## 2. 账号与连接体系：局域网自动发现 vs. 云端手动添加

手机端将连接目标划分为【本地账号（局域网电脑）】与【云端账号（公网服务器）】两类，支持多实例保存与一键切换。

### 2.1 本地账号（局域网自动发现 —— 映射电脑端本地账号）
- 桌面端本地后端支持监听 `0.0.0.0:<PORT>`（开启局域网可访问模式，在桌面端设置中提供开关并支持配对管理）。
- 暴露轻量化设备发现接口 `GET /api/discovery/info`（仅返回电脑主机名、操作系统类型、唯一实例 ID、版本号、端口，不泄露任何敏感数据或凭证）及 UDP/mDNS 发现响应。
- **局域网强鉴权边界**：`127.0.0.1` / `::1` 本机回环请求保持免鉴权兼容；所有来自非本机回环地址（局域网 IP）的业务接口与 WebSocket 连接（除 `/api/discovery/info`、`/api/system/health` 与配对接口外），必须强制校验 `Authorization: Bearer <DeviceToken>`（或用于资源标签/WS 的 `?token=<DeviceToken>`）。桌面端提供已配对手机设备列表及“一键吊销 Token”功能。
- **手机端局域网自动发现机制（原生插件 + 分批兜底）**：
  1. **主力协议（mDNS / Bonjour / UDP 广播）**：通过原生插件（`LanDiscovery`）探测局域网内的桌面端实例，实现秒级发现。
  2. **兜底扫描（`/24` 子网 IP 段分批并发扫描）**：通过原生插件获取手机当前局域网 IP 所在的 `/24` C 段子网，在用户主动触发或广播无结果时，按每批 25 个 IP 分批并发 + 单请求 800ms 超时探测 `/api/discovery/info`。
- **首次配对鉴权与自动重连**：
  - 手机首次连接局域网电脑时发起 `POST /api/lan/pair/request`，桌面端弹窗/通知展示 6 位配对码，手机端弹窗输入配对码调用 `POST /api/lan/pair/verify` 换取长效 `DeviceToken` 并保存于原生安全存储（`@capacitor/preferences` + `localStorage`）；后续打开 App 自动静默重连。

### 2.2 云端账号（公网手动添加 —— 映射云端无头服务器）
- 连接部署在公网 Linux 服务器上的无头后端（`DEPLOY_ENV=cloud`）。
- 用户在手机端手动添加（HTTPS/WSS 地址、端口、Token、备注名），支持增删改查并在本地局域网节点与多个云端节点之间一键无缝切换（动态切换 `BaseURL`、`AuthToken`、`WebSocket` 并刷新会话缓存）。

## 3. 移动端视角下的“双层执行环境”映射与权限表现

1. **连接【本地账号（局域网电脑）】时**：
   - Bot 电脑对应局域网电脑虚拟桌面容器（若状态为 `uncreated`，手机端点击“Bot 电脑”同样跳转至管理员 Bot 并自动发送初始化 Prompt）。
   - 你的电脑（宿主机）即该局域网电脑本身，遵循 `policy.js` 与 `hostComputer.executionMode` 审批机制。
2. **连接【云端账号（公网服务器）】时**：
   - Bot 电脑即云端 Linux 环境（Ready）。
   - **你的电脑（宿主机）联动**：通过 `GET /api/computer/hosts` 与 `POST /api/computer/hosts/select` 检测在线 `host_executor` 宿主机列表；若有多台在线则允许选择目标宿主机；若无在线宿主机则 UI 置灰标记 `"宿主机离线/不可用"`。

## 4. 移动端 UI 导航结构、设计参考映射与网络容错

### 4.1 移动端导航架构与截图页面映射（双层堆栈导航 + Bottom Sheet）
1. **一级首页：Bot 列表页（对齐截图 #1）**：顶部栏左上角当前连接节点头像（带在线角标）、右上角 `+` 新建 Bot；上方居中置顶主 Bot（大尺寸吉祥物 + ★）；下方专职 Bot 与群聊列表；底部悬浮搜索框 + 左下角技能商店/工具入口（适配 Safe Area）。
2. **二级页面：全屏对话页 + 能力面板 Bottom Sheet**：点击 Bot 推入全屏对话页（顶部返回按钮 + 底部软键盘/Safe Area 适配）；顶部右侧面板按钮呼出 **能力面板 Bottom Sheet**（Tab：`电脑画面`、`职责与记忆`、`即将进行`、`资料库`）。
3. **个人设置与连接节点切换页（对齐截图 #2）**：顶部 `连接节点切换器` 卡片（点击展开本地发现/云端节点切换 Bottom Sheet）；`用量与账单`（无订阅入口）；`保险库`；`技能商店`（严禁使用“连接应用”占位文案）；`Bot` 分区（`权限`、`自动设置时区`、`时区`、`Bot 电脑` / `宿主机状态`）。
4. **创建 / 编辑 Bot 页（对齐截图 #3 / #4）**：创建新 Bot（大头像预览 + 名称 + 13 形状 + 11 颜色 + `创建`）；编辑 Bot（隐藏 Phase 2 `语音通话` 区块）。
5. **技能商店页（替换截图 #5）**：保留分类胶囊（`全部`/`办公`/`平台技能`）与底部搜索框布局，渲染真实平台技能（含 KimiCU）、办公技能（QQ 邮箱 / 通用邮箱）与自定义共享技能入口。

### 4.2 网络状态容错与断线重连
1. **局域网 3 秒快速失败与切云端弹窗**：本地局域网请求配置 3 秒短超时；不可达时提示 `“当前无法连接至局域网电脑，请检查是否处于同一 Wi-Fi 或切换至云端账号”` 并提供 **【一键切换至云端账号】** 按钮。
2. **前后台切换保活与增量同步**：监听 `visibilitychange` 与 Capacitor `App.appStateChange`，回到前台立即健康探活、静默重连 `/ws` 并同步当前会话增量事件。
