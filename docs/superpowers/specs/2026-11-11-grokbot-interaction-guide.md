# GrokBot 对话交互、卡片输入框与消息回复反馈复刻指导规范

本文档整理自 **xAI Grok Bot** 官方机制文档、v0.77.0+ 结构化提问卡更新记录、Auto-Review 审批规范及原版桌面端实机取证，作为 TwinkleBot 对话流、内联卡片输入框与消息回复/表情反馈系统的工程复刻基准。

## 1. 基本对话交互方式（Core Conversational UX）
- **前置即时回应气泡（Pre-Action Ack Bubble）**：当模型在调用工具的同一轮次输出前置口语说明（`turn.text` 非空且含 `turn.calls`）时，立即发射 `{ type: "assistant_text", text, interim: true }` 气泡，实现“先回话告知 → 后台执行 → 输出结果”的真人队友对话节奏。
- **分段多气泡与连续圆角组（Multi-Bubble Grouping）**：长回复按语义段落（代码块外的空行分段）拆分为连续紧凑的多气泡组（间距 `4px`，连续侧圆角 `6px`），每段气泡均可独立悬停回复或点亮表情。
- **主对话流零调试噪音**：默认不在主时间线平铺 `thought`、`action`、`result` 调试胶囊；执行中仅展示单行呼吸态进度条（支持一键联动“Bot 的电脑”或打开“执行轨迹抽屉”），执行完毕自动消隐。
- **居中时间聚类分隔条**：替代逐条气泡时间戳，相邻消息间隔 `>= 5 分钟` 时居中插入时间分隔条；上滑阅读历史时提供回到底部浮标。

## 2. 卡片输入框与结构化交互卡片（Inline Card Inputs）
- **结构化澄清提问卡（`ask_user_choice`）**：
  - 支持单问题及多问题分步卡片（`questions[]` Stepper `1/N`）、单选/多选（`multiSelect`）、键盘快捷键（`A`–`F`）。
  - 内置 **`"Your own answer"`（输入你自己的回答…）卡片内自定义输入框**，点击原地展开单行输入并支持回车提交。
  - 状态闭环：`Active` → `Resolved`（原地折叠为问题 + 已选徽章/自定义回答，不重复生成用户气泡）→ `Superseded`（用户在底部主输入框直接发新消息时自动置灰关闭旧卡片）。
- **Auto-Review 审批与内联规则编辑卡（`approval_request`）**：
  - 自然语言动作摘要 + 紧凑参数预览，提供 `允许`、`暂不允许`、`始终允许` 及 **`编辑规则…`（卡片内展开 `每次先询问 / 自动允许` 与匹配模式输入框）**，完成后折叠为单行回执胶囊。
- **可编辑草稿确认卡（`propose_draft`）与内联凭据安全输入卡（`request_credential`）**：
  - 外发内容支持在卡片输入框内直接修改标题与正文后确认发送；登录/验证码需求支持掩码输入并可选存入密码库（Vault），绝不明文回显。

## 3. 消息回复、划词引用与动作化表情反馈（Reply, Quote & Feedback）
- **双向 `╭─` 线程引用回复**：每条气泡具备独立寻址，点击 `↩` 在底部暂存台展示引用预览条（`Esc` 取消），发送后在气泡顶部渲染 `╭─ [原消息摘要]` 连接胶囊（支持点击平滑滚动定位并高亮闪烁原气泡）；群聊中回复特定 Bot 自动优先路由该 Bot 作答。
- **桌面端划词引用（Highlight-to-Quote）**：鼠标选中气泡内文字浮现 `❝ 引用 | 复制` 工具条，一键将摘录片段作为引用芯片加入输入框暂存台。
- **持久化与动作化表情反馈（Actionable Reactions）**：
  - 多表情面板（`👍 ❤️ 😂 🎉 ⏰ 📌 👎`）落盘持久化至会话事件流。
  - 动作联动：`⏰` 自动创建次日 09:00 待办提醒；`📌` 一键摘录归档至右侧资料库（Library）；`👎` 在气泡下方展开**内联纠错反馈卡片输入框**，提交后自动沉淀为私有技能/职责约束。

## 4. 底部胶囊输入框与暂存台（Composer & Staging）
- **一体式圆角卡片容器**：内部上方整合引用回复条、划词引用块与待发附件/粘贴截图缩略图，支持 `Ctrl/Cmd+V` 粘贴截图与拖拽上传。
- **右侧三态动态主按钮**：空闲无输入时为 Bot 主题色语音波形 `|||`，输入内容或挂载附件时变为发送箭头 `↑`（运行中输入新内容亦可直接插话重定向），运行中且输入为空时变为停止方块 `■`。
- **`/` 斜杠快捷指令菜单**：支持 `/teach`、`/schedule`、`/clear`、`/auto` 及私有技能模糊检索调用。
