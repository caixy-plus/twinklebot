# 聊天交互卡片与对话协同机制

## 对话内 6 类内联交互卡片

TwinkleBot 会在聊天流中渲染富交互卡片，无需让用户切出聊天窗口：

1. **提问卡（`ask_user_choice`）**：支持单选、多选、多题步进（`1/N`）以及末尾自定义文本输入；桌面端失焦时可用数字 `1–6` 或字母 `A–F` 秒选；若提问挂起期间用户在输入框直接打字插话，旧提问卡会自动标记为已跳过。
2. **草稿确认卡（`propose_draft` / `mail_send_message`）**：发送外部邮件、帖子或重要对外消息前弹出，用户可在卡片内直接内联编辑主题和正文后点击确认发送或取消。
3. **凭据安全卡（`request_credential` / `skill_configure_channel` 缺密弹出）**：当页面需要密码或 2FA 验证码且保险库无记录时，卡片加密接收用户输入并可选同步存入保险库，仅向工具提供不可见明文的不透明句柄 `secret_ref`。
4. **权限审批卡（`ApprovalCard`）**：涉及高风险宿主机/跨工作区操作或桌面关键动作时弹出，支持「本次允许」「拒绝」，并可点击内置规则编辑器（`.btn-edit-rule`）一键将规则写入「设置 → 权限」的放行或询问列表。
5. **HTML / SVG 沙盒预览卡（`MarkupPreviewCard`）**：当 Bot 回复包含 ```svg``` 或 ```html``` 代码块时自动渲染安全隔离的实时预览卡（禁止同源权限），支持浅色 / 透明格 / 深色三种底色切换、刷新、一键复制源码、切换源码视图以及全屏三档视口预览。
6. **文件投递卡（`send_file`）**：支持将工作区或下载目录中的任意格式文件（`.docx`、`.pdf`、`.xlsx`、`.pptx`、`.csv`、`.md`、`.html`、`.zip`、图片等）直接以卡片投递到聊天流（支持打开 / 定位 / 下载）；若原文件被删或移出工作区会显示缺失置灰提示。

## 消息级高频操作

- **悬停/轻触回复与划词引用**：悬停桌面消息（或轻触手机气泡）点击「回复此消息」可锚定引用并在跳转时高亮闪烁目标气泡；选中任意消息正文文本后会出现划词引用浮条，支持复制或作为引用筹码附带到下一条提问（可叠加多条引用）。
- **历史用户消息「修改并重发」**：可内联修改任意历史用户消息，系统会从该条起截断后续 DOM、NDJSON 事件与对话历史后按新内容重跑（不可中断回滚前请谨慎，支持先「清空」或通过顶栏「分享」保存快照）。
- **三入口附件上传**：支持点击 `+` 选文件、输入框直接粘贴图片、以及把文件拖拽到聊天舞台，单文件上限 10MB。
- **运行中实时操控**：
  - **Live Steering（非打断插话）**：Bot 运行过程中用户直接发送补充消息，系统会在本步/工具返回后无损注入上下文继续响应，不会破坏多 `tool_call` 配对。
  - **停止与自然语言停止**：点击「停止」按钮或发送纯停止口令（「停下」「stop」）可立即中止本轮执行（不会误杀类似 `"stop nginx"` 的正常技术指令）。
  - **单轮步数上限续接**：达到单轮最大工具步数时会展示暂停提示卡，用户点击 **「继续执行」** 可原上下文无缝接续下一段任务。

## 多 Bot 协同与群聊路由

- **Bot 独立隔离**：每个专职 Bot 拥有独立人设（右栏编辑）、独立私有工作区与资料库目录、以及独立 `专属记忆` 和 `即将进行` 定时任务。右栏底部支持「派生专职新 Bot 并交接」直接带记忆克隆新 Bot。
- **跨 Bot 通信抽屉**：主/专职 Bot 可通过 `list_bots`、`create_bot`、`send_bot_message`（含 4 跳防死循环护栏）、`workspace_search` 协同工作，对话中出现紧凑交流胶囊，点击打开完整协同细节抽屉。
- **群聊协调规则**：多 Bot 群聊支持 `@BotName` 点名（按**最长前缀优先**匹配，例如优先 `@谷歌账号管家` 而非 `@谷歌`）、**回复优先路由**（引用哪位 Bot 优先由谁回答）与基于职责人设打分自动选人，单轮群内最多连续接力 3 个 Bot 回合；成员顺序与增删可在群设置编辑。
