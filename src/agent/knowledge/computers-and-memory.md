# 双电脑环境、浏览器引擎与记忆日程体系

## 「Bot 的电脑」vs「你的电脑」双环境分工

TwinkleBot 明确区分两台电脑环境，各有独立权限与看屏交互方式：

1. **Bot 的电脑（隔离 Ubuntu 沙盒）**：
   - 运行在独立 Ubuntu XFCE 虚拟桌面中（macOS 基于 OrbStack，Windows 基于 WSL2 Ubuntu，端口 `:7300` / `:6080`）。
   - **权限特性**：在沙盒内的 CLI（`run_shell`）、文件读写与 GUI/浏览器操作（含 `click`、`type_text`、`browser_click`、`browser_type` 等）**全部自动放行，无需用户逐次确认**（仅跨 Bot 专属目录、敏感宿主机路径与用户手动添加的询问规则受限，保护宿主机不受影响）。
   - **内置看屏接管**：App 右侧栏「Bot 的电脑」（及移动端顶部看屏入口）内置实时画面。需要主人查看进度、扫二维码、过验证码或人工登录时，引导点击面板并可随时点 **「取得控制权」**（暂停 Bot 操作由主人接管键鼠，点恢复后 Bot 自动补截图续跑）。**切勿在聊天里直接粘贴 `http://127.0.0.1:6080/...` 裸地址**。
   - **环境初始化（仅管理员 Bot）**：由管理员 Bot 执行 `computer_provision(action: "probe" | "install")` 与 `system_diagnostics(action: "update_bot_computer")` 一键完成环境部署、执行器注入与健康探活；跨网云端场景需先在本地电脑激活宿主机协同角色。
2. **你的电脑（用户本机宿主机）**：
   - 使用 `host_run_shell`、`host_open`、`host_read_file`、`host_write_file` 访问主人本机文件或运行本机命令行（macOS 用 zsh，Windows 自动使用 UTF-8 PowerShell）。
   - **权限受控**：受「设置 → 电脑 → 你的电脑 → 在这台电脑上执行」（`始终允许` / `每次询问` / `从不允许`）及「设置 → 权限 → 高风险操作智能确认」保护。设为「始终允许」时，常规命令行、开发构建、`/tmp`/本 Bot 工作区清理与非敏感文件编辑直接放行；破坏性命令（如 `sudo`、用户主目录/系统目录 `rm`、`git push --force`）、敏感系统配置及 `.ssh`/`.env`/钥匙串等硬编码红线依然受控。
   - **KimiCU macOS 后台 GUI 操控（可选平台技能）**：在 macOS 上添加 `kimi-cu` 后通过本地 MCP 协议连接本机已安装的 KimiCU（**自动发现工具列表与版本能力，免更新即可适配升级**），支持窗口截图、AX 控件树、后台键鼠、剪贴板粘贴、多路径拖拽与系统状态订阅，且**不抢占物理鼠标指针**；Windows 宿主机不支持 KimiCU，禁止向 Windows 用户提及 `.app` 等 Mac 路径。

## 3 种浏览器自动化引擎模式

在 **「设置 → 电脑 → 浏览器引擎」** 可设全局默认，也可在任意 **Bot 右栏检查器** 中单独覆盖：

1. **Bot 电脑 Chrome（默认 · 保留登录态）**：运行在 Ubuntu 沙盒 Chrome（CDP `:9222`），跨 Bot 共享登录态与 Cookie，可在「Bot 的电脑」实时观看与手动接管（含并发屏幕预算池排期）。
2. **本机 Chrome Headless（省 CPU · 无登录态）**：直接跑在宿主机原生 Chrome 无头模式，不占 Ubuntu 虚拟桌面屏幕配额，渲染最快，但**使用临时空白 Profile，没有已保存的个人登录态且不在 noVNC 中显示**。
3. **本机 Chrome Debug（独立调试 Profile）**：在本机拉起独立 Chrome 调试窗口（默认端口 `9223`），不混用用户个人日常浏览器数据，适合在本机窗口内手动登录后持续复用。

## 专属记忆、全局记忆、定时任务与资料库

- **两层记忆分工**：
  - **专属记忆（右栏 `专属记忆`）**：仅对当前 Bot 生效（例如该专职 Bot 的特定文风、汇报格式、固定账号习惯），可在右栏单独启停开关或增删改。
  - **全局共享记忆（`设置 → 通用 → 全局共享记忆`）**：主人个人偏好、全局规范等跨所有 Bot 生效的信息。
  - **静默直存与自动提炼**：当主人明确要求「记住…」时直存落库，对话结束后快模型也会异步静默提炼有价值的长期事实与去重（**不会弹出打扰性的记忆推荐确认卡**）。
- **定时例行任务（右栏 `即将进行` & `schedule_manage`）**：所有定时任务统一由 **5 段标准 Cron 表达式** 驱动（UI 预设弹窗会实时校验并预览执行频率），到期后自动唤醒对应 Bot 静默执行并将结果留存于会话记录与未读提示中。
- **资料库（右栏 `资料库` & `library_manage`）**：汇总展示当前 Bot 工作区内全部图片、生成媒体、投递文件与保存的 Markdown 报告笔记；每个 Bot 的工作区目录彼此隔离。
