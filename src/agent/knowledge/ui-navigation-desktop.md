# 桌面端与网页端界面导航地图

## 三栏主界面结构

TwinkleBot 桌面应用与桌面网页采用左、中、右三栏布局：

- **左栏（Bot 列表与全局入口）**：
  - 顶部功能条：收起/展开紧凑侧边栏（`#compact-sidebar-btn`，快捷键 `⌘\` / `Ctrl+\`）、全局搜索（`⌘K` / `Ctrl+K`）、新建 Bot / 发起群聊（`+`）。
  - 会话列表：置顶主管理员 Bot（默认 `Twinkle`）与普通专职 Bot、多 Bot 协作群聊；未读蓝点累加并在进入对话后清零。
  - 底部固定区：左下角 **技能商店** 入口与 **账号头像菜单**（`本地账号` / `云端账号` 切换、全局用量与账单、快捷键帮助、`设置` 弹窗入口 `⌘,` / `Ctrl+,`、桌面应用退出等）。
- **中栏（对话舞台）**：
  - 顶栏：当前 Bot 头像与名称、`清空` 历史记录、`分享`（克隆/导出对话上下文）。
  - 消息流：流式思维胶囊（`≤ 9` 字实时状态摘要）、用户与 Bot 气泡、交互卡片（提问卡/草稿卡/凭据卡/审批卡/预览卡/文件卡）、多 Bot 交流胶囊；上滚浏览历史时右下角浮现「回到底部」按钮。
  - 输入区：支持多行输入、粘贴图片、拖拽/选择附件（最大 10MB）、`@Bot` 群聊点名自动补全、以及运行中「停止」或 **Live Steering 非打断插话**（随时补充说明，不丢已完成的工具调用）。
- **右栏（检查器 Inspector，`⌘I` / `Ctrl+I` 切换）**：
  - 顶部双页签：**「动态」** 与 **「资料库」**（支持 `全部 / 媒体 / 文件` 筛选，保存 Bot 工作区产出、AI 生图、文件及笔记，点击图片可打开大图灯箱）。
  - 「动态」页包含：**职责与人设**（编辑人设与头像 13 形状 × 11 颜色）、**派生专职新 Bot 并交接**（克隆 Bot 含记忆）、**浏览器引擎**（单 Bot 覆盖或跟随全局）、**专属记忆**（当前 Bot 私有规则）、**即将进行**（基于 5 段 Cron 的例行定时任务）、**Bot 的电脑**（实时桌面缩略图、全屏查看与「取得控制权」开关，以及多屏并发排队徽章）、**模型用量**（智能路由档位、当前会话 token 消耗与用量明细）。

## 设置弹窗 8 大页签（完整目录）

点击左下角账号菜单 → **「设置」**（或按 `⌘,` / `Ctrl+,`）打开设置弹窗，左侧共 8 个菜单页签，顺序与核心内容如下：

1. **通用**：个人昵称与 6 色头像、外观主题（浅色 / 深色 / 跟随系统）、Bot 主题强调色、输入拼写检查、界面语言（跟随系统 / 中文 / English）、智能模型路由总开关与单轮预算上限、上下文压缩 3 档预设卡（50% / 75% / 85% + 自定义规则）、**全局共享记忆**（对全部 Bot 生效的规则 CRUD）。
2. **外网中继** *(独立页签，位于「通用」正下方，仅本机桌面端支持 `remote-relay-v1` 时显示)*：
   - 外网访问与内网穿透总开关及连接状态徽章（未启用 / 启动中 / 重连中 / 已连接 / 异常）。
   - 运行模式：`内置托管 frpc（推荐）` 或 `外部自建反代`、公网访问地址、强鉴权中继访问令牌（查看 / 复制 / 轮换令牌，注意本机主端口不放开免密外网访问，专口强制 Bearer 鉴权）。
   - `frpc` 连接参数（服务端域名/IP、端口、WSS TLS / TCP / QUIC 协议、WebSocket 路径、代理名、远程映射端口、frps 握手令牌、本机中继端口、防 Mac 空闲休眠 `caffeinate`）与「保存并应用」「重启隧道」「检测公网连通性」。
   - **手机快捷扫码配对**二维码与配对链接复制（`twinklebot://...`）、旧版 `geminibot-frpc` 一键迁移横幅、可折叠 **VPS 服务端配置生成（`frps.toml` + `Caddyfile`）** 与脱敏运行日志。
3. **模型接入与路由**：3 档智能路由模型绑定（极速档 Fast / 中等档 Medium / 高级档 Advanced）与生图模型绑定（Image），以及多供应商（Gemini / Vertex AI / OpenAI / DeepSeek / OpenAI 兼容）的增删改、模型拉取与连通性测速。
4. **电脑**：
   - **你的电脑**：宿主机执行策略（「始终允许」「每次询问」「从不允许」，设为从不允许会自动停用 Mac `kimi-cu`）。
   - **浏览器引擎**：默认 3 模式切换（Bot 电脑 Chrome / 本机 Chrome Headless / 本机 Chrome Debug CDP + 端口配置）。
   - **远端宿主机 & 局域网设备配对**：查看已连接的跨网宿主机状态、局域网开关、已配对设备与 6 位局域网配对审批。
   - **Bot 的电脑**：Ubuntu 沙盒探针、一键初始化/修复组件（仅管理员 Bot 可触发 `provision`）、更新组件与 **屏幕并发预算池**（`auto` 均衡或自定义并发屏幕数）。
5. **权限**：安全审核总开关（`auto-audit`）、**每次询问规则（askRules）** 与 **直接放行规则（allowRules）** 的增删改。
6. **保险库**：本机 AES-256-GCM 静态加密存储的凭据、账号与联系人管理（支持分类筛选、关键词搜索、查看/更新/删除加密密码；模型仅能获取不透明句柄 `secret_ref`，无法读取明文）。
7. **用量与账单**：全局与分 Bot 账单统计、各供应商实时余额/账单刷新、周期筛选与手动余额校准。
8. **关于与诊断**：当前版本、Web/Core OTA 热更新检查、下载应用与一键回滚，以及底层运行时/执行器/MCP/网络自检信息。

## 桌面端全局快捷键一览

- `⌘K` / `Ctrl+K`：打开全局搜索命令面板（搜 Bot 与历史消息并直达跳转）。
- `⌘,` / `Ctrl+,`：打开设置弹窗。
- `⌘\` / `Ctrl+\`：切换紧凑侧边栏。
- `⌘I` / `Ctrl+I`（输入框未聚焦时）：折叠 / 展开右侧检查器。
- `1`–`6` 或 `A`–`F`（输入框未聚焦且存在待回答提问卡时）：秒选提问卡对应选项并提交。
- `Enter` / `Shift+Enter`（聊天输入框内）：`Enter` 直接发送消息，`Shift+Enter` 插入换行（中文输入法 `compositionend` 后 50ms 保护窗口防误发）。
- `@`（群聊输入框内）：唤起成员点名自动补全列表。
- `Esc`：按优先级栈依次关闭最上层浮层（图片大图灯箱 → Bot 交流抽屉 → 拒绝当前挂起审批卡 → 清空引用/关闭搜索与弹窗/Popover）。
