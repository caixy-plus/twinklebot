# 移动端界面导航与手势指南

## 页面结构与返回手势

TwinkleBot 移动端（Capacitor 原生 iOS/Android App 与手机浏览器自适应视图）采用两级页面模型：

- **两级视图切换**：
  1. **会话列表视图**：展示置顶管理员 Bot、所有专职 Bot 与群聊；顶部含搜索框、新建 Bot / 群聊按钮、账号与设置入口。
  2. **对话视图**：顶部显示返回按钮、当前 Bot 名称/状态、「Bot 的电脑」屏幕查看入口以及右上角 **`...` 更多菜单**（含查看右侧检查器动态/资料库、清空记录、删除对话）。
- **手势与系统返回**：
  - **左缘右滑返回**：在对话页或抽屉左缘向右滑动可流畅退回上一层。
  - **Android 硬件返回键优先出栈栈**：弹窗 / Alert → 技能详情与商店 → 设置 / 编辑 / 检查器 / 账号抽屉 → 对话页退回会话列表 → 会话列表最小化应用（`minimizeApp`）。

## 移动端账号面板（纯本地/云端双端模型）

- 移动端 **没有桌面端本机宿主机账号**，右上角/列表顶栏「切换账号」打开移动端账号管理抽屉，严格分为两类：
  1. **本地账号（局域网直连）**：点击「扫描局域网」自动发现同一 Wi-Fi 下桌面端，或手动输入局域网 IP + 端口；首次连接需在桌面端「设置 → 电脑」确认或输入 **6 位数字配对码** 换取永久设备令牌。
  2. **云端账号（外网穿透 / 云端部署）**：支持点击 **「扫码添加」**（Android 使用锁定竖屏的 `PortraitCaptureActivity` + ZXing，iOS 使用 `AVCaptureSession` 原生相机直接扫桌面端「设置 → 外网中继」生成的二维码），或手动输入公网 HTTPS 地址与强鉴权令牌 / 配对链接（`twinklebot://...`）。
- 若手机端尚未配置任何账号或当前所选远端账号断连失联，界面会自动显示全屏 **账号断连门禁页**，提供一键切换其他在线账号、局域网扫描/配对或扫码添加云端账号入口，探活成功前保持门禁锁定防误操作。

## 移动端设置抽屉与子页入口

- 移动端设置抽屉保留高频常用入口：个人头像/账号卡片、**用量与账单**、**保险库**、**权限**、**模型接入与路由**、**语言切换**、**更多设置**（打开通用配置，如上下文压缩、全局记忆、外观等），以及底部 **关于 TwinkleBot**（版本号徽章与移动端 Web OTA 在线检查/更新进度）。
- 注意：**「外网中继」配置仅在桌面端本地运行环境可用**，不会出现在移动端。

## 移动端专属聊天与看屏交互

- **输入法换行与送信不收键盘**：移动端聊天框 `enterKeyHint="enter"`，键盘按 `Enter` 只插入换行、必须点击右侧蓝白箭头按钮 `#send-btn` 发送；发送消息后会保持输入框焦点与软键盘开启，仅当用户上滑浏览历史消息、点击其他控件、切回会话列表或切换 Bot 时自动收起软键盘。
- **点击气泡显示操作栏**：手机端无鼠标悬停，轻触某条消息气泡即可切换展开回复、引用、修改并重发、复制等操作栏。
- **全屏查看「Bot 的电脑」**：打开手机端「Bot 的电脑」弹窗会临时解锁横屏观看远程桌面，并在屏幕右下角提供 **远程软键盘开关按钮（`#screen-keyboard-btn`）**，方便直接用手机输入法在 Ubuntu 远程窗口打字；关闭后自动恢复竖屏锁定。
